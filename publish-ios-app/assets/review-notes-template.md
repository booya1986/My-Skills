# App Review Notes

## Review path

- Describe the shortest path from launch to the primary feature.
- List the exact visible control labels for every supported device class whose
  responsive layout changes navigation (for example, iPhone and iPad).
- List any permission prompt and why it appears.
- If login is required, reference credentials stored only in App Store Connect.

## Paid products

- List each product included in this submission and the feature it unlocks.
- Explain how the reviewer reaches purchase and Restore Purchases on every
  supported device class, including the exact purchase CTA and any scrolling.
- State whether any free access is app-managed or an App Store introductory offer.
- If free access and purchase appear together, state whether purchase is
  immediately available or which real gate the reviewer must satisfy.

## Dependencies and edge cases

- Explain required network, account, hardware, location, or content dependencies.
- Mention any behavior that could otherwise look unavailable or incomplete during review.
