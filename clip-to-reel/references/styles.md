# Choosing a style (step 0 — always ask)

Show the user this table and the two preview sheets, then ask which style this reel uses. Never pick for them.
Preview sheets: `assets/target-look-scenes.jpg` (A) and `assets/style-b/target-look.jpg` (B).

| | **A · Paper split** (Jack Roberts) | **B · Editorial collage** (Vox-style) |
|---|---|---|
| **Feels like** | clean Apple keynote on warm paper | a magazine cut out with scissors, animated |
| **Face** | bottom half of a split screen, big and sharp | small rounded card, bottom centre (or a large card when the face source is sharp) |
| **Graphics** | Apple-like windows, real logos, pixel letters, highlighter sweeps, check badges | vintage paper-cut collages (halftone B&W cutouts, torn paper, graph scraps) generated and animated with Higgsfield, plus minimal white UI: chat bar being typed, scrolling doc, "Generating" pill, cursor |
| **Backgrounds** | beige paper (split), white / cool-grey studio (full screen), one dark beat | off-white dot grid (UI), full-bleed collage |
| **Captions** | heavy grey 1–3-word chips with hard shadow, on the seam | flat near-black chip, medium weight, one row above the face card |
| **Rhythm** | snap-zoom + whoosh on every cut, slow push-ins | stop-motion jitter, fast bursts of 0.1 s shots, slow push-ins, cursor clicks |
| **Ending** | full-screen paper CTA card, huge keyword in quotes | collage sign held up with the keyword on it, green sub-chip |
| **Accent colour** | rust `#B84A26` | the client's brand colour (e.g. green `#22C55E` + charcoal) |
| **Cost** | no credits | ~15 Higgsfield images (1 credit each) + ~8 animations (45 credits each at 1080p) ≈ 380 credits |
| **Best when** | the face source is good and the topic is software/UI | the topic is conceptual, or the face source is weak |
| **Files** | `references/design-system.md`, `assets/reference-composition.html`, `references/judge-prompt.md` | `references/style-b/design-system.md`, `assets/style-b/reference-build.py`, `references/style-b/judge-prompt.md` |

Ask also: the brand accent colour (B), and whether spending Higgsfield credits is OK (B). Report credits
before and after every Higgsfield call — the user wants to see what each step cost and what is left.
